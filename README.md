
# Лабораторна робота №1

## Тема
Бібліотеки Mocha, Chai.

## Мета
Ознайомлення з методикою роботи з
бібліотеками Mocha та Chai.

## Об'єкт тестування
Бібліотека Mtrx:
https://github.com/zhufuge/Mtrx

## Використані інструменти
- JavaScript
- Node.js
- Mocha
- Chai
- Mtrx
- Visual Studio Code

## Виконана робота
Створено автоматизовані тести основних функцій
бібліотеки Mtrx.

Перевірено:
- створення матриць;
- властивості матриць;
- додавання та віднімання;
- множення;
- транспонування;
- визначник і ранг;
- перевірку типу та розмірів матриць.

## Запуск тестів

npm install
npm test
